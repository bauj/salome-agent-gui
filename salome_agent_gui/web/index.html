Ask anything about SALOME: each question is answered from the SALOME documentation, with links to the pages used. RAG searches the index once and answers; agentic RAG lets the model search and read pages several times, which is slower but follows harder questions. Questions are answered one by one, without memory of the previous ones. Choose Agentic assistant at the top of the window to build models. The first message starts a conversation: I propose a plan, you approve or edit it, and each stage is built in this SALOME study. Follow-up messages change that model ("make the roof taller", "add a chimney"). Undo and Redo step through turns; Rebuild recreates the study from the model when they got out of sync; New conversation starts over. While a conversation is open it keeps the agent server to itself. result.py and report.md are linked after each turn. Attach sketches, photos or drawings with the paperclip, by dropping them on the window or by pasting them: the model is built from what they show.
